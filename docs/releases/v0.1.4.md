A fix release: no more console windows popping up on Windows.

## What's fixed

- **The agent no longer flashes a Terminal window about once a minute.** On Windows machines where `pool install` set the agent up to start at logon (an install from a non-elevated shell), each call the agent made to the `tailscale` command-line tool opened a new console, which Windows 11 shows as a Terminal window. The agent now starts `tailscale` without a console. Agents installed to start at boot weren't affected.

## Build and release changes

- Every GitHub Action the build and release workflows use is pinned to an exact commit, and CI now scans the full history for leaked secrets with gitleaks.
- The workflows use `actions/checkout` v7 and `actions/setup-go` v7.

## Install

1. Download the binary for your platform below, and `SHA256SUMS`.
2. Verify it:
   - Linux/macOS: `sha256sum -c SHA256SUMS --ignore-missing`
   - Windows: `Get-FileHash pool-0.1.4-windows-amd64.exe` and compare.
   - Build provenance: `gh attestation verify pool-0.1.4-windows-amd64.exe --repo montjeffrey/compute-pool`
3. Rename it to `pool` (or `pool.exe`) and put it on your `PATH`.

To upgrade a Windows agent, run `pool install` with the same flags as before from an elevated shell, so the agent keeps starting at boot.

See the [v0.1.0 notes](https://github.com/montjeffrey/compute-pool/releases/tag/v0.1.0) for what pool does, and [SECURITY.md](https://github.com/montjeffrey/compute-pool/blob/v0.1.4/SECURITY.md) before you run an agent.

## Known limits

- **Binaries are not code-signed yet.** Windows may show "Unknown publisher" or a SmartScreen warning, and on a PC with Smart App Control turned on it may refuse to run them at all ("An Application Control policy has blocked this file"). Smart App Control judges each file separately, so one release can run while the next is blocked. On macOS, clear the quarantine flag with `xattr -d com.apple.quarantine pool`.
- **From a non-elevated shell, `pool install` can't read the running agent's flags**, so it says so instead of confirming them.
