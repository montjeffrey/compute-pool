A performance release: shipped programs start faster, and files an agent already has are no longer uploaded again.

## What's new

- **Shipped programs start without a new antivirus scan per task.** Each task used to get a fresh copy of the shipped program, and Windows Defender scans every new program file before it runs: about half a second per task on a laptop. The program now runs as a hard link to the agent's cached copy, which is checked against its SHA-256 before every use. Other shipped files are still copied, so a task can't change another task's input.
- **No re-uploads between runs.** The client now asks an agent for its cached copy before sending a file, so a new `pool map` doesn't re-send the same program to every slot.

On a desktop plus a laptop lending 8 cores, a CPU-bound batch now runs **1.31× faster** than on the desktop alone (1.09× with v0.1.1), and the laptop does a third of the work instead of a sixth.

Upgrade both the agents and the device you send jobs from to get both improvements. Older clients and agents still work with these.

## Install

1. Download the binary for your platform below, and `SHA256SUMS`.
2. Verify it:
   - Linux/macOS: `sha256sum -c SHA256SUMS --ignore-missing`
   - Windows: `Get-FileHash pool-0.1.2-windows-amd64.exe` and compare.
   - Build provenance: `gh attestation verify pool-0.1.2-windows-amd64.exe --repo montjeffrey/compute-pool`
3. Rename it to `pool` (or `pool.exe`) and put it on your `PATH`.

See the [v0.1.0 notes](https://github.com/montjeffrey/compute-pool/releases/tag/v0.1.0) for what pool does, and [SECURITY.md](https://github.com/montjeffrey/compute-pool/blob/v0.1.2/SECURITY.md) before you run an agent.

## Known limits

- **Binaries are not code-signed yet.** Windows may show "Unknown publisher" or a SmartScreen warning, and on a PC with Smart App Control turned on it may refuse to run them at all ("An Application Control policy has blocked this file"). Smart App Control judges each file separately, so one release can run while the next is blocked. On macOS, clear the quarantine flag with `xattr -d com.apple.quarantine pool`.
- **Re-running `pool install` with new flags doesn't restart an agent that is already running**, so the new flags apply only after the agent restarts. Restart it with `Stop-ScheduledTask` and `Start-ScheduledTask` on the "compute-pool agent" task.
